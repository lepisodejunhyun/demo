# 자동 생성 API 클라이언트 — sdk.gen.ts, types.gen.ts

**파일 위치:**
- `libs/api-client/src/sdk.gen.ts`
- `libs/api-client/src/types.gen.ts`
- `libs/api-client/src/client.gen.ts`
- `libs/api-client/src/index.ts`

---

## 이게 왜 필요한가?

Angular에서 NestJS 서버의 API를 호출하려면 HTTP 요청 코드를 직접 작성해야 해요.

**직접 작성하면:**

```typescript
// 이렇게 매번 수동으로 작성해야 함
const response = await fetch('http://localhost:3000/api/admins/signin', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ email, password }),
});
const data = await response.json();
```

문제점:
1. URL을 직접 문자열로 작성 → 오타 가능성
2. 서버 API가 바뀌면 프론트도 수동으로 수정해야 함
3. 응답 타입을 모름 → TypeScript 자동완성 없음

**자동 생성 방식을 쓰면:**

```typescript
// 이렇게 깔끔하게 사용 가능
const result = await adminControllerSignin({
  body: { email, password }  // TypeScript 자동완성 제공
});
// result.data가 AdminDto 타입임을 TypeScript가 앎
```

---

## 자동 생성 흐름

```
NestJS 서버 (admin.controller.ts)
    ↓ @ApiOkResponse, @ApiOperation 데코레이터들이
    ↓ Swagger 스펙(JSON)을 자동 생성
    ↓
http://localhost:3000/api-docs-json
    ↓ pnpm generate:api 실행
    ↓ openapi-ts가 이 JSON을 읽어서
    ↓
libs/api-client/src/ 폴더에 TypeScript 파일 자동 생성
├── types.gen.ts   ← 타입 정의
├── sdk.gen.ts     ← API 함수들
└── client.gen.ts  ← HTTP 클라이언트
```

## types.gen.ts — 자동 생성된 타입들

```typescript
// This file is auto-generated by @hey-api/openapi-ts

export type ClientOptions = {
  baseUrl: string;
};

export type AdminDto = {
  /** 관리자 고유 식별자 */
  id: string;
  /** 이메일(로그인ID) */
  email: string;
  /** 관리자 이름 */
  name: string;
  /** 관리자 권한 등급 */
  role: '관리자' | '최고관리자';
  /** 연속 로그인 실패 횟수 */
  failCount: number;
  /** 관리자 계정 잠김 시간 */
  lockedUntil: string;
  /** 관리자 계정 마지막 로그인 시간 */
  lastLoginAt?: string | null;
  /** 관리자 계정 생성 시간 */
  createdAt: string;
  /** 관리자 계정 수정 시간 */
  updatedAt: string;
  /** 관리자 계정 삭제 시간 */
  deletedAt?: string | null;
};

export type AdminSignInDto = {
  /** 관리자 이메일 */
  email: string;
  /** 관리자 비밀번호 */
  password: string;
};

export type AdminControllerSigninData = {
  body: AdminSignInDto;      // 요청 body에 들어갈 데이터
  path?: never;
  query?: never;
  url: '/api/admins/signin'; // 요청 URL
};

export type AdminControllerSigninResponses = {
  /** 로그인 성공 */
  200: AdminDto;             // 200 응답일 때 반환 타입
};
```

### 서버 DTO와 자동 생성 타입 비교

**서버 (NestJS):**

```typescript
// apps/server/src/app/admin/dtos/admin.dto.ts
export class AdminDTO {
  @ApiProperty({ description: '관리자 고유 식별자' })
  @Expose()
  id: string;

  role: AdminRole;  // AdminRole은 Prisma enum
  ...
}
```

**클라이언트 (자동 생성):**

```typescript
// libs/api-client/src/types.gen.ts
export type AdminDto = {
  id: string;
  role: '관리자' | '최고관리자';  // enum → union type으로 변환됨
  ...
}
```

서버의 `AdminDTO` 클래스가 `AdminDto` 타입으로 자동 변환돼요. 주석도 그대로 옮겨와요!

## sdk.gen.ts — 자동 생성된 API 함수들

```typescript
// This file is auto-generated by @hey-api/openapi-ts

import type { Client, Options as Options2, TDataShape } from './client';
import { client } from './client.gen';
import type { ... } from './types.gen';

export type Options<...> = Options2<...> & {
  client?: Client;
  meta?: Record<string, unknown>;
};

// GET /api/admins/hello
export const adminControllerGethello = <ThrowOnError extends boolean = false>(
  options?: Options<AdminControllerGethelloData, ThrowOnError>
) => (options?.client ?? client).get<AdminControllerGethelloResponses, unknown, ThrowOnError>({
  url: '/api/admins/hello',
  ...options
});

// GET /api/admins
export const adminControllerFindAll = <ThrowOnError extends boolean = false>(
  options?: Options<AdminControllerFindAllData, ThrowOnError>
) => (options?.client ?? client).get<AdminControllerFindAllResponses, unknown, ThrowOnError>({
  url: '/api/admins',
  ...options
});

// POST /api/admins/signin
export const adminControllerSignin = <ThrowOnError extends boolean = false>(
  options: Options<AdminControllerSigninData, ThrowOnError>
) => (options.client ?? client).post<AdminControllerSigninResponses, unknown, ThrowOnError>({
  url: '/api/admins/signin',
  ...options,
  headers: {
    'Content-Type': 'application/json',
    ...options.headers
  }
});
```

### 함수 하나씩 분석

**`adminControllerGethello`**

```typescript
export const adminControllerGethello = (options?) =>
  client.get({ url: '/api/admins/hello', ...options });
```

`GET /api/admins/hello` 요청을 보내는 함수예요.

```typescript
// 사용 예시
const result = await adminControllerGethello();
```

---

**`adminControllerFindAll`**

```typescript
export const adminControllerFindAll = (options?) =>
  client.get({ url: '/api/admins', ...options });
```

`GET /api/admins` 요청을 보내는 함수예요. 관리자 목록을 가져와요.

```typescript
// 사용 예시
const result = await adminControllerFindAll();
// result.data는 AdminDto[] 타입 (배열)
```

---

**`adminControllerSignin`**

```typescript
export const adminControllerSignin = (options) =>
  client.post({
    url: '/api/admins/signin',
    ...options,
    headers: { 'Content-Type': 'application/json', ...options.headers }
  });
```

`POST /api/admins/signin` 요청을 보내는 함수예요. 로그인할 때 사용해요.

```typescript
// 사용 예시
const result = await adminControllerSignin({
  body: {
    email: 'admin@test.com',
    password: 'abc123!@#'
  }
});

// result.data는 AdminDto 타입 (로그인된 관리자 정보)
console.log(result.data.name); // "최고 관리자"
```

### `ThrowOnError` 타입 매개변수

```typescript
export const adminControllerSignin = <ThrowOnError extends boolean = false>(
  options: Options<AdminControllerSigninData, ThrowOnError>
) => ...
```

기본값이 `false`예요. 에러가 나도 throw하지 않고 result 객체로 반환해요.

```typescript
// ThrowOnError = false (기본값)
const result = await adminControllerSignin({ body: {...} });
if (result.error) {
  // 에러 처리
}

// ThrowOnError = true
// 에러 발생 시 throw됨 (try-catch 필요)
```

## client.gen.ts — HTTP 클라이언트

```typescript
// This file is auto-generated by @hey-api/openapi-ts

import { type ClientOptions, type Config, createClient, createConfig } from './client';
import type { ClientOptions as ClientOptions2 } from './types.gen';

export const client = createClient(createConfig<ClientOptions2>());
```

`createClient()` — fetch 기반의 HTTP 클라이언트를 생성해요.

`app.config.ts`에서 `client.setConfig()`를 호출하면 이 클라이언트에 서버 주소가 설정돼요.

`index.ts`는 외부에서 이 라이브러리를 사용할 때의 **공식 진입점**이에요.

```typescript

```

`sdk.gen.ts`나 `types.gen.ts`를 직접 import하지 않아도 `index.ts`를 통해 모두 접근 가능해요.

## 자동 생성의 장점

### 서버 API가 바뀌면?

예를 들어 서버에 `lastLoginAt` 필드를 추가했다고 해요.

1. `admin.prisma`에 필드 추가
2. `admin.dto.ts`에 `@Expose() lastLoginAt` 추가
3. 서버 재시작

그러면 Swagger 스펙이 자동으로 업데이트돼요.

```bash
pnpm generate:api  # 이 명령 한 번이면
```

`types.gen.ts`가 자동으로 업데이트:
```typescript
export type AdminDto = {
  ...
  lastLoginAt: string | null;  // 자동으로 추가됨!
};
```

Angular 코드에서 자동으로 새 필드에 접근 가능해요.

---

### 타입 동기화

서버의 `AdminDTO` 클래스와 클라이언트의 `AdminDto` 타입이 항상 동일하게 유지돼요.

```
서버 AdminDTO             클라이언트 AdminDto
─────────────────         ─────────────────────
id: string          →     id: string
email: string       →     email: string
role: AdminRole     →     role: '관리자' | '최고관리자'
```

수동으로 클라이언트 타입을 관리하지 않아도 돼요.

## API 클라이언트 사용 흐름 정리

```
1. 서버에서 API 작성
   admin.controller.ts에 새 엔드포인트 추가
   @ApiOkResponse({ type: SomeDTO }) 데코레이터 추가
       ↓
2. 서버 실행
   pnpm nx serve server
       ↓
3. API 클라이언트 생성
   pnpm generate:api
   → http://localhost:3000/api-docs-json 에서 스펙 읽기
   → libs/api-client/src/ 파일들 자동 생성
       ↓
4. Angular에서 사용
   import { someNewFunction } from '@api-client';
   const result = await someNewFunction({ body: {...} });
   result.data  // 타입이 자동으로 지정됨
```

## 전체 파일 관계 정리

```
libs/api-client/src/
├── types.gen.ts      ← 서버 DTO → 클라이언트 타입
│                        AdminDto, AdminSignInDto, 요청/응답 타입
│
├── sdk.gen.ts        ← API 함수 목록
│                        adminControllerSignin(), adminControllerFindAll()
│
├── client.gen.ts     ← HTTP 클라이언트 인스턴스
│                        fetch 기반, baseUrl 설정용
│
└── index.ts          ← 배럴 파일 (공식 진입점)
                         sdk.gen.ts + types.gen.ts를 모아서 export


tsconfig.base.json의 path alias:
  "@api-client"         → libs/api-client/src/index.ts
  "@api-client/client"  → libs/api-client/src/client.gen.ts


사용처:
  import { adminControllerSignin } from '@api-client';   // index.ts 통해서
  import { client } from '@api-client/client';           // client.gen.ts 직접
```
