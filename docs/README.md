## 추천 읽기 순서

처음 보는 분이라면 이 순서로 읽으세요:

### 1단계 — 일단 돌려본다
**[04-getting-started.md](04-getting-started.md)** — 설치/실행/관리 가이드
- 컴퓨터에 도구 설치 → 의존성 설치 → DB 띄우기 → 서버/admin 실행까지.
- "이 프로젝트를 처음 받은 사람" 시점.

### 2단계 — 큰 그림을 잡는다
**[03-architecture-decisions.md](03-architecture-decisions.md)** — 왜 이렇게 만들었나
- Nx, NestJS, Angular, Prisma, Docker 등 기술 선택 이유.
- 각 기술이 어떤 문제를 해결하는지 비유와 함께.

### 3단계 — 한 사이클을 끝까지 따라가본다
**[01-flow-walkthrough.md](01-flow-walkthrough.md)** — 로그인 end-to-end 추적
- 사용자가 로그인 버튼을 누르면 → admin → 네트워크 → 서버 → DB → 응답 → 화면까지.
- 15단계로 나눠 코드와 함께 설명.

### 4단계 — 직접 새로 만들어본다
**[02-new-domain-recipe.md](02-new-domain-recipe.md)** — 새 도메인 추가 레시피
- 예시: "게시판" 도메인을 처음부터 만들기.
- 필요한 15~20개 파일을 어떤 순서로 작성하는지.
