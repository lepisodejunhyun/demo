# 정책

### 로그인 정책

| 정책 항목 | 정책 상세 설명 | 제약 사항 |
| --- | --- | --- |
| 인증 방식 | 이메일과 비밀번호를 통한 기본 인증 | ID/PW 필수 입력 |
| 비밀번호 복잡도 | 보안을 위한 비밀번호 조합 규칙 | 영문+숫자+특수문자 포함 8~20자 |
| 에러 메시지 | 이메일/비밀번호 오류 시 동일한 메시지 표시 | "이메일 또는 비밀번호가 올바르지 않습니다." |
| 삭제 계정 처리 | 삭제된 계정으로는 로그인 불가 | 활성 상태인 계정만 허용 |

### FAQ 관리 정책

| 정책 항목 | 정책 상세 설명 | 제약 사항 |
| --- | --- | --- |
| 목록 조회 | 등록된 FAQ 전체 목록을 조회 | 등록일시 역순 정렬 |
| 상세 조회 | 질문과 답변 내용을 확인 | - |
| 등록 | 질문과 답변을 입력하여 FAQ 등록 | 질문, 답변 필수 입력 |
| 수정 | 기존 FAQ의 질문 또는 답변을 수정 | 질문, 답변 필수 입력 |
| 삭제 | 선택한 FAQ를 삭제 | 삭제 전 확인 안내 |

### 공지사항 관리 정책

| 정책 항목 | 정책 상세 설명 | 제약 사항 |
| --- | --- | --- |
| 목록 조회 | 등록된 공지사항 전체 목록을 조회 | 등록일시 역순 정렬 |
| 상세 조회 | 공지사항 제목과 내용을 확인 | - |
| 등록 | 제목과 내용을 입력하여 공지사항 등록 | 제목, 내용 필수 입력 |
| 수정 | 기존 공지사항의 제목 또는 내용을 수정 | 제목, 내용 필수 입력 |
| 삭제 | 선택한 공지사항을 삭제 | 삭제 전 확인 안내 |

# DB 설계

### 관리자 테이블 (Admin)

| 컬럼명 | 타입 | 제약사항 | 기본값 | 설명 |
| --- | --- | --- | --- | --- |
| id | UUID | Primary Key | uuid() | 고유 식별자 |
| email | VARCHAR | Unique, Not Null | | 로그인 이메일 |
| password | VARCHAR | Not Null | | bcrypt 해시 비밀번호 |
| name | VARCHAR | Not Null | | 관리자 이름 |
| role | ENUM | Not Null | 관리자 | 관리자 / 최고관리자 |
| failCount | INT | Not Null | 0 | 로그인 실패 횟수 |
| lockedUntil | DATETIME | Nullable | | 계정 잠금 해제 시각 |
| lastLoginAt | DATETIME | Nullable | | 마지막 로그인 시각 |
| createdAt | DATETIME | Not Null | now() | 생성 일시 |
| updatedAt | DATETIME | Not Null | now() | 수정 일시 (자동 갱신) |
| deletedAt | DATETIME | Nullable | | Soft Delete 시각 |
